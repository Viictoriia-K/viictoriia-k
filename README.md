### Инструменты и технологии
- Моделирование процессов и систем:
  BPMN (AS-IS, TO-BE), UML (Use Case, Sequence, State Machine), DFD
- Требования:
  SRS, Use Case, User Story, Job Story, User Story Mapping, критерии приёмки, ПМИ
- Интеграции и API:
  REST, SOAP, OpenAPI (Swagger), Postman, JSON, XML (XSD, WSDL)
- Данные:
  SQL (PostgreSQL), ER-диаграммы, нормализация до 3НФ, словари данных, Excel
- Прототипирование:
  Figma
- Инструменты:
  Jira, Confluence, draw.io, Miro, DBeaver, Google Docs
- Нейросети:
  промптинг, проверка результата на достоверность
- Технический бэкграунд:
  сети (CCNA, TCP/IP), Wireshark
